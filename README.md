# TrueWork cho máy tính

Bản cài TrueWork (Windows, macOS) của TrueAds. Trang tải: https://hoangnvnam.github.io/truework-desktop/

- **Windows:** [TrueWork-Windows-Setup.exe](https://github.com/hoangnvnam/truework-desktop/releases/latest/download/TrueWork-Windows-Setup.exe)
- **macOS (chip Apple):** [TrueWork-macOS.dmg](https://github.com/hoangnvnam/truework-desktop/releases/latest/download/TrueWork-macOS.dmg)

Repo này chỉ chứa bản cài và trang tải. App tự kiểm `latest.json` của bản phát hành mới nhất để báo cập nhật.
